# Commentator

An AI-powered video narrator that reads a video file and produces a new version with an extra audio layer of spoken commentary generated by an LLM.

## How it works

1. **Frame extraction** – ffmpeg pulls one frame from the video every N seconds.
2. **Vision commentary** – Each frame is sent to a GPT model (with vision support, e.g. `gpt-5.4-mini`) which returns a 1–2 sentence description of the scene.
3. **Text-to-speech** – The commentary text is converted to speech via the Azure OpenAI TTS deployment (voice `onyx` by default).
4. **Audio mixing** – ffmpeg overlays the speech clips on top of the original audio at the correct timestamps and re-encodes the audio track.
5. **Output** – The final video file has the same video track as the input but with the mixed audio (original + AI narrator).

## Installation

```bash
# 1. Clone the repo
git clone https://github.com/rafaelzacarias/Commentator.git
cd Commentator

# 2. Create and activate a virtual environment (recommended)
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 3. Install Python dependencies
pip install -r requirements.txt

# 4. Configure credentials
cp .env.example .env
# Edit .env with your API key(s)
```

## Configuration

Copy `.env.example` to `.env` and fill in the values:

### Azure OpenAI (required)

```dotenv
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com
AZURE_OPENAI_KEY=your-azure-openai-key
AZURE_OPENAI_DEPLOYMENT=gpt-5.4-mini   # chat / vision deployment
AZURE_TTS_DEPLOYMENT=tts               # TTS deployment name
AZURE_OPENAI_API_VERSION=2024-12-01-preview
```

### Optional tuning

| Variable | Default | Description |
|---|---|---|
| `COMMENTARY_INTERVAL` | `10` | Seconds between commentary clips |
| `TTS_VOICE` | `onyx` | Narrator voice (`alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`) |

## Usage

```bash
python main.py <input_video> [options]
```

### Arguments

| Argument | Description |
|---|---|
| `input` | Path to the input video file |
| `-o`, `--output` | Output path (default: `<input>_commented.mp4`) |
| `--interval N` | Commentary every N seconds (default: 10) |
| `--voice VOICE` | TTS voice (default: `onyx`) |

### Examples

```bash
# Basic usage – output saved as my_clip_commented.mp4
python main.py my_clip.mp4

# Custom output path and 15-second interval
python main.py my_clip.mp4 -o narrated.mp4 --interval 15

# Use the "nova" voice
python main.py my_clip.mp4 --voice nova
```

## Notes

- Processing time depends on video length, interval, and API latency.  A 60-second video with a 10-second interval makes ~6 LLM calls and ~6 TTS calls.
- The original audio is preserved at 80% volume so the narrator is clearly audible.
- Commentary clips are generated sequentially; very long videos may take several minutes.
- The video codec is copied as-is; only the audio track is re-encoded (AAC 192 kbps).
